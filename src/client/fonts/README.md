# Fonty interfejsu

Pliki TTF są niezmienionymi fontami z publicznego repozytorium Google Fonts. Aplikacja serwuje je lokalnie; użytkownik nie pobiera fontów z zewnętrznego CDN.

- Raleway: https://github.com/google/fonts/blob/main/ofl/raleway/Raleway%5Bwght%5D.ttf — font zmienny, w tekście używamy wariantu Light 300. SHA-256: `8bbcc3eb8275c388f4bcd998832f8a4b943eadbaf6a595205312774b5951aefb`.
- Barlow Condensed Bold: https://github.com/google/fonts/blob/main/ofl/barlowcondensed/BarlowCondensed-Bold.ttf — wąski font dla H1, nagłówków i przycisków, dobrany jako zamiennik Champions Gothic. SHA-256: `e476562ec9c1e16cf16475895b511f08c804f438cc9a9f80a44ea50a0eeb5b65`.

Obie licencje SIL OFL 1.1 znajdują się w tym folderze. Zachowano nazwy, glify i oryginalne pliki; fontów nie poddano modyfikacji ani wycinaniu znaków.
