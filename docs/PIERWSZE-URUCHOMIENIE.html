Instrukcja dla pierwszego uruchomienia

Przetestuj narzędzie w GitHub.
Bez osobnego hostingu i Canva.

Użyj GitHub Codespaces: to komputer do testów, który obsługujesz w przeglądarce. Po uruchomieniu aplikacji otworzysz jej prywatny adres i wgrasz zdjęcie.

Potrzebujesz konta GitHub, dostępu do repozytorium PrzeBeetohoven22/Impact-image-modifier i jednego zdjęcia prelegenta. Kod dostajesz w gotowym ZIP-ie razem z tą instrukcją. Nie musisz instalować programów na komputerze.

O kosztach: Codespaces korzysta z limitu Twojego konta GitHub. Konta osobiste Free i Pro mają miesięczny limit wliczony w plan; po jego wyczerpaniu uruchomienie może wymagać płatności. Sprawdź ustawienia rozliczeń GitHub. Ta metoda nie wymaga zakupu osobnego hostingu.

Instrukcja działa również bez internetu; GitHub wymaga połączenia.

1 Pobierz i rozpakuj kod

  1. W odpowiedzi w czacie kliknij plik Impact-image-modifier-gotowy-kod.zip i pobierz go.
  2. Na Windows kliknij ZIP prawym przyciskiem → Wyodrębnij wszystkie → Wyodrębnij. Na Macu kliknij ZIP dwukrotnie.
  3. Otwórz rozpakowany folder. W środku powinny być bezpośrednio pliki package.json i package-lock.json oraz foldery src, assets i .devcontainer.
.devcontainer/   ← ustawienia automatycznej instalacji
assets/          ← wybrany gradient
src/             ← kod aplikacji
docs/            ← instrukcje
package.json
package-lock.json
README.md
… pozostałe pliki z paczki

Folder zaczynający się kropką też jest potrzebny. Na Macu pokaż ukryte pliki skrótem ⌘ + Shift + .; na Linuxie zwykle Ctrl + H.

2 Wgraj pliki do GitHub

  1. Zaloguj się w GitHub i otwórz swoje repozytorium Impact-image-modifier.
  2. Jeżeli repozytorium jest puste, kliknij link uploading an existing file w polu „Quick setup”. Jeżeli widzisz już listę plików, kliknij Add file → Upload files.
  3. Przeciągnij na stronę GitHub całą zawartość rozpakowanego folderu: pliki i podfoldery, w tym .devcontainer. Wgraj zawartość, aby package.json znalazł się w głównym katalogu repozytorium.
  4. Poczekaj, aż zakończy się wgrywanie. Wpisz opis zapisu, np. Pierwsza wersja narzędzia.
  5. Jeśli widzisz wybór gałęzi, wybierz Commit directly to the main branch. Kliknij Commit changes, aby zapisać pliki.

Sprawdź: na głównej liście plików repozytorium widać package.json oraz folder .devcontainer. Dopiero wtedy przejdź dalej.

GitHub nie rozpakuje ZIP-a za Ciebie. Wgrywasz rozpakowane pliki. „Commit” oznacza zapis kodu; w pustym repozytorium ten przebieg nie wymaga pull requesta ani łączenia gałęzi.

3 Utwórz środowisko Codespaces

  1. Na stronie repozytorium kliknij zielony przycisk Code.
  2. W otwartym oknie wybierz zakładkę Codespaces.
  3. Kliknij Create codespace on main. Jeśli Twoja gałąź ma inną nazwę, przycisk pokaże tę nazwę.
  4. Poczekaj na otwarcie edytora i zakończenie przygotowania środowiska. Pierwsza instalacja może potrwać kilka minut. Dołączona konfiguracja wybiera Node 24, instaluje biblioteki i buduje aplikację.

Domyślna konfiguracja wymaga maszyny z co najmniej 2 rdzeniami i 8 GB RAM. W oknie tworzenia Codespaces GitHub pokazuje, kto rozlicza sesję. Nie musisz podawać kluczy ani logować się do Canva.

4 Uruchom aplikację jedną komendą

  1. W edytorze otwórz menu ≡ lub pasek menu → Terminal → New Terminal.
  2. W dolnym panelu kliknij miejsce do wpisywania poleceń.
  3. Wklej poniższą komendę i naciśnij Enter.
bash .devcontainer/start.sh

Dobry wynik: w terminalu pojawi się „Serwer zdjęć uruchomiony na porcie 3001.”

Pozostaw ten terminal uruchomiony. Jeśli pojawi się „Najpierw wykonaj…”, użyj komendy naprawczej opisanej na końcu instrukcji.

5 Otwórz swój prywatny adres aplikacji

  1. W dolnym panelu edytora kliknij zakładkę Ports, obok Terminal. Jeśli nie widać zakładki, sprawdź menu … tego panelu.
  2. Znajdź wiersz z numerem 3001 i etykietą „Zdjęcia prelegentów”. Jeśli go nie ma, kliknij Forward a Port / Add port, wpisz 3001 i zatwierdź Enterem.
  3. Sprawdź, że Visibility ma wartość Private. W razie potrzeby kliknij wiersz prawym przyciskiem → Port Visibility → Private.
  4. Najedź na adres w tym wierszu i kliknij ikonę globusa Open in Browser. Otworzy się nowa karta z narzędziem.

To jest Twój URL do testów. Skopiujesz go z paska adresu nowej karty. Adres jest przydzielany przez GitHub, używa HTTPS i zwykle kończy się na -3001.app.github.dev.

Sprawdź: widzisz „Zdjęcia prelegentów” i podgląd wybranego gradientu. Przy ustawieniu Private dostęp wymaga Twojego zalogowanego konta GitHub.

6 Przygotuj pierwsze zdjęcie

  1. W polu DODAJ ZDJĘCIE NA IMPACT'27 wybierz JPEG, PNG lub WebP z jedną osobą. Plik może mieć maksymalnie 20 MB; krótszy bok powinien mieć co najmniej 300 pikseli.
  2. Kliknij GENERUJ GRAFIKĘ NA IMPACT'27. Gradient jest już gotowy. Tło zostanie usunięte automatycznie; PNG z wyciętą sylwetką jest rozpoznawany bez wyboru trybu.
  3. Poczekaj na wynik. Jeśli aplikacja prosi o sprawdzenie zdjęcia, obejrzyj je i potwierdź jedną osobę. Przy kilku osobach wybierz inne zdjęcie.
  4. Sprawdź Pomiar głowy: włosy–broda. Jeśli linie nie pasują, ustaw je na wyciętej sylwetce i kliknij Zastosuj pomiar głowy. Przy braku wykrytej twarzy pomiar jest obowiązkowy. Docelowa wysokość głowy wynosi 45% widocznej sylwetki; możesz wybrać 30–55% i kliknąć Aktualizuj podgląd.
  5. Jeśli chcesz, rozwiń Filtry sylwetki, zmień wartości i kliknij Zastosuj filtry.
  6. Po sprawdzeniu wyniku kliknij Pobierz PNG. Gotowy plik Impact'27 photo.png ma 1600 × 1200 pikseli i zawiera sylwetkę połączoną z Twoim gradientem.

Pobierz wynik podczas tej sesji. Zdjęcia i zadania są przechowywane w pamięci maksymalnie 20 minut; restart aplikacji również je usuwa. Tło i pozycje sylwetki są stałe. Prowadnice nie trafiają do pobranego PNG. Automatyczny pomiar głowy i jakość maski trzeba sprawdzić na zdjęciu. Ciasne źródło może dać głowę do 65% sylwetki, z ostrzeżeniem. Powyżej tego limitu wybierz inne zdjęcie.

7 Po testach zatrzymaj Codespaces

  1. Po pobraniu PNG otwórz github.com/codespaces.
  2. Znajdź sesję przypisaną do repozytorium Impact-image-modifier.
  3. Kliknij … po prawej → Stop codespace.

Zatrzymanie kończy używanie czasu procesora. Pliki sesji pozostają zapisane i nadal zajmują miejsce w limicie konta. Samo zamknięcie karty przeglądarki nie oznacza natychmiastowego zatrzymania sesji.

Następnym razem: wejdź na github.com/codespaces, kliknij nazwę istniejącej sesji, otwórz terminal i ponownie wpisz bash .devcontainer/start.sh. Następnie otwórz port 3001. Kod zwykle nie wymaga ponownej instalacji; zdjęcie trzeba wgrać ponownie.

Gdy coś nie działa

Co widziszCo zrobić
W GitHub widać tylko ZIPWróć do kroku 2 i wgraj rozpakowaną zawartość paczki.
Brak .devcontainer lub package.json w głównym kataloguUzupełnij pliki z paczki w głównym katalogu repozytorium. Dopiero wtedy utwórz Codespaces.
Brak komendy „Create codespace” lub komunikat o limicieSprawdź zalogowane konto, dostęp do repozytorium i pozostały limit Codespaces. Konto organizacji może mieć dodatkowe ograniczenia.
„Najpierw wykonaj…” albo brak folderu distW terminalu wykonaj bash .devcontainer/setup.sh. Po zakończeniu ponownie uruchom komendę z kroku 4.
Błąd „Wymagany Node.js 24”Sprawdź pliki .devcontainer. Po ich uzupełnieniu otwórz paletę poleceń przez F1 i wybierz Codespaces: Rebuild Container.
Port 3001 nie otwiera stronySprawdź komunikat uruchomienia w terminalu. W panelu Ports protokół powinien być HTTP; zewnętrzny URL GitHub i tak używa HTTPS. Otwórz stronę ponownie przez ikonę globusa.
„Żądanie z niedozwolonej strony”Otwórz adres z Ports dla portu 3001. W terminalu aplikacji naciśnij Control + C, a potem wykonaj git pull --ff-only origin main && npm run build && bash .devcontainer/start.sh. Po uruchomieniu odśwież kartę aplikacji i ponownie wybierz zdjęcie. Jeśli Git zgłosi konflikt, zatrzymaj się i podaj komunikat.
„Address already in use” / EADDRINUSEAplikacja prawdopodobnie już działa. Otwórz port 3001. Jeśli trzeba ją zrestartować, użyj Ctrl + C w terminalu, w którym ją uruchomiono.
Podgląd zniknął lub zadanie wygasłoWgraj zdjęcie ponownie. Wynik nie jest przechowywany jako historia.

Jeśli utkniesz: skopiuj ostatnie linie błędu z terminala i podaj numer kroku tej instrukcji. Nie są potrzebne hasła ani klucze Canva.
